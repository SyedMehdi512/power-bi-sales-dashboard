# Power BI Sales Dashboard

## Project Overview
An interactive sales dashboard developed using Microsoft Power BI to analyze sales performance and present business insights through visualizations.

## Tools Used
- Microsoft Power BI
- Power Query

## Key Analysis
- Sales and revenue performance
- Profit analysis
- Product and category performance
- Regional sales trends
- Time-based sales analysis

## Objective
To transform sales data into meaningful visual insights and support data-driven business decisions.
